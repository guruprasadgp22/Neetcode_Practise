## About

This repository is synced automatically from NeetCode using its GitHub Sync feature. Every time I submit a solution on NeetCode, it gets committed here. Problems I revisited have more than one submission, so you can see how my approach changed over time (for example, a brute force first, then an optimized version).

## Repository structure

```
Data Structures & Algorithms/
├── two-integer-sum/
│   ├── submission-2.java
│   ├── submission-3.java
│   └── ...
├── binary-search/
│   └── submission-0.java
└── ...
```

- Each folder is one problem, named with its NeetCode problem slug.
- Each `submission-N.java` file is one attempt. A higher number means a later attempt.
- Some numbers are missing because only selected submissions were synced.

## How to use

1. Browse to a problem folder under `Data Structures & Algorithms/`.
2. Open the latest `submission-N.java` for my most recent approach.
3. To run one locally, paste the `Solution` class into the matching problem on [NeetCode](https://neetcode.io/practice) or LeetCode, or add a `main` method and compile it with `javac`.
